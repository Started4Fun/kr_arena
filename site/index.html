Champion Stats

A small Discord bot that turns opt-in Arena match records into a simple answer: which champions finished in first place, and how many times?

How it works Data & policy
Product overview

Aggregate stats for a private Discord community

The bot is designed for a small community. A server administrator registers Riot IDs with the account holder's consent. The bot retrieves public match data, filters Arena games, and presents aggregate champion counts in Discord.

Focused question

Find the champions that finished in 1st place and count their first-place appearances.

Small, private scope

Designed for a private Discord server and a registered sample of Korean server accounts.

No gameplay advice

No real-time information, automated actions, cheats, overlays, or recommendations are provided.

Discord commands

Simple commands, readable results

/arena-playerShow aggregate first-place champion counts for one registered Riot ID.
/arena-summaryCombine the registered sample and remove duplicate matches.
/arena-addAdd an account to the server's consented statistics sample.
/arena-removeRemove an account from the sample.
Data & API usage

What the bot uses

  • Account-V1: resolves a Riot ID to a PUUID.
  • Match-V5: retrieves match IDs and match details for registered accounts.
  • Data Dragon: provides localized Korean champion names.
  • Arena filtering: recognizes Arena queue IDs 1700 and 1710 and the Arena game mode.
Privacy and display scope

The bot stores Riot IDs and PUUIDs only for the registered statistics sample. It displays aggregate champion names and first-place counts, not raw match histories or unrelated personal information. An account can be removed from the sample by the server administrator.
